# peopleandco-blog-media

Public CDN storage for peopleandco.me blog images, served via jsDelivr
(`https://cdn.jsdelivr.net/gh/Kawaii-Yuki-Kun/peopleandco-blog-media@main/...`).

Managed entirely by the `peopleandco` Laravel app via the GitHub Contents
API — images are pushed here on blog create/update and removed on delete.
Do not edit files in this repo by hand; changes made outside the app will
be overwritten or go unnoticed by it.
